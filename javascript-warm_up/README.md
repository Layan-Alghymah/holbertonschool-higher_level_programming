# JavaScript - Warm up

This project is part of the Holberton School Higher Level Programming curriculum.

## Description
An introduction to JavaScript programming using Node.js.

## Learning Objectives
- Understand JavaScript variables and data types.
- Use const and let.
- Work with conditions and loops.
- Define and call functions.
- Manipulate objects and arrays.
- Import and export modules.
- Run JavaScript scripts using Node.js.

## Requirements
- Ubuntu 20.04 LTS
- Node.js 14.x
- Semistandard 16.x
- All scripts must be executable.
- All scripts must start with `#!/usr/bin/node`.

## Usage
Run a JavaScript file using:

```bash
node 0-javascript_is_amazing.js
