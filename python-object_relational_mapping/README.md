# Python - Object-relational Mapping

This project explores how to connect Python applications to MySQL
databases using MySQLdb and SQLAlchemy ORM.

## Learning Objectives

- Connect to a MySQL database from a Python script.
- Retrieve, insert, update, and delete database records.
- Use parameterized queries to prevent SQL injection.
- Explain object-relational mapping (ORM).
- Map Python classes to database tables.
- Query and manage mapped objects using SQLAlchemy.
- Define relationships between states and cities.

## Requirements

- Ubuntu 20.04 LTS
- Python 3.8.5
- MySQL 8.0
- mysqlclient 2.0.x (MySQLdb)
- SQLAlchemy 1.4.x
- pycodestyle 2.7.*
