# Python - Serialization

## Description
This project is part of the Holberton School Higher Level Programming curriculum. It focuses on serialization and deserialization in Python, exploring how data can be converted into different formats for storage, transmission, and retrieval.

## Learning Objectives
- Understand serialization and deserialization.
- Learn the difference between serialization and marshaling.
- Work with JSON, Pickle, CSV, and XML formats.
- Serialize and deserialize Python objects.
- Read and write structured data to files.

## Tasks

### 0. Basic Serialization
Serialize a Python dictionary to a JSON file and deserialize it back into a dictionary.

**File:** `task_00_basic_serialization.py`

### 1. Pickling Custom Classes
Use Python's `pickle` module to serialize and deserialize custom class instances.

**File:** `task_01_pickle.py`

### 2. Converting CSV Data to JSON Format
Read data from a CSV file and convert it into JSON format.

**File:** `task_02_csv.py`

### 3. Serializing and Deserializing with XML
Serialize Python data into XML and deserialize XML back into Python data.

**File:** `task_03_xml.py`
